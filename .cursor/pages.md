# Required Pages

- `/login` → Common login page
- `/register` → Admin only
- `/admin/dashboard` → Manage users, donors, students
- `/admin/sponsorships` → Approve/reject sponsorship requests
- `/admin/reports` → Approve/reject student reports and receipts
- `/donor/dashboard` → Browse students, request sponsorships
- `/donor/students` → View assigned students and their approved reports
- `/mentor/dashboard` → View assigned students, submit session notes
- `/student/dashboard` → Submit weekly and academic reports, upload receipts
- `/student/status` → See approvals, notifications
